#*AI Resume Analyzer (ATS Checker)*

This project is an AI-powered Resume Analyzer built using Streamlit and Large Language Models.
It simulates how an Applicant Tracking System (ATS) evaluates a resume against a job description and provides clear, actionable feedback.

The app helps candidates understand how well their resume matches a job role, what keywords are missing, and how they can improve their profile.

#*Features*

1. Upload resume in PDF format
2. Paste any Job Description
3. AI evaluates resume like a real ATS
4. Match percentage (0–100)
5. Missing or weak keywords
6. Strengths in the resume
7. Professional profile summary
8. Simple and fast Streamlit interface

#*Tech Stack*

1. Python
2.Streamlit – Web UI
3. LangChain
4. ChatGroq
5. PyPDF2 – PDF text extraction
6. dotenv – Environment variable handling
